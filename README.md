# Karim Hawwa's portfolio

The site behind [karimhawwa.tech](https://www.karimhawwa.tech), built with React 19, Vite, Tailwind CSS 4 and GSAP.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run lint
```

- **Projects**: the `PROJECTS` list at the top of `src/Projects.jsx`; images live in `src/assets/projects/`.
- **About, experience, education and skills**: `src/Info.jsx`.
- **CV**: replace `src/assets/Karim's CV.pdf`.
